# Security Policy

## Supported versions

Only the latest release is supported with security updates. Older releases do
not receive patches, so please upgrade to the newest version before reporting
an issue.

## Reporting a vulnerability

Please report security vulnerabilities privately rather than opening a public
issue. This gives us time to prepare a fix before the details become public.

- Preferred: use
  GitHub's [private vulnerability reporting](https://github.com/Micnubinub/syncthing-android/security/advisories/new)
  on the Security tab.
- Include the affected version, a description of the issue, and steps to reproduce if possible.

You will receive a response acknowledging the report. We will keep you informed
of progress and coordinate a public disclosure date with you. I am doing this in my spare time,
so please understand response times may be slow

## Upstream vulnerabilities

This project wraps [Syncthing](https://github.com/syncthing/syncthing). If the
issue affects Syncthing itself rather than the Android wrapper, report it to
the upstream project following
their [security policy](https://github.com/syncthing/syncthing/blob/main/SECURITY.md).
